
## Overview
 
This project demonstrates an end-to-end data engineering solution using Python, Pandas, Google Cloud Storage (GCS), and BigQuery.
 
The solution includes:
 
- Data ingestion and cleansing using Python and Pandas
- Secure storage of cleaned data in Google Cloud Storage
- Loading data into BigQuery for analysis
- Window function analysis using SQL
- Regional spending aggregation and reporting
- IAM and Service Account configuration following cloud security best practices
